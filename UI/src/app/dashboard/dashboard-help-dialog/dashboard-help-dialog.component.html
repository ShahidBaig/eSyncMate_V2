Dashboard — Help Guide

See today's order flow at a glance and drill into anything that needs attention

info What the Dashboard Shows

dashboardOverview

Everything on this page is driven by the date range and customer filter at the top. Counts are based on when the order reached eSyncMate, not the marketplace order date — so an old order that arrived today still counts as today's.

event Choosing the Date Range

The dashboard opens on TODAY. Switch ranges with the chips or pick your own dates:

today
TODAY (default) Only what arrived today — the view you want when starting your day
schedule
24H / 7D / 30D Rolling windows ending today — useful for spotting a trend
date_range
Custom range Pick a start and end date; the chips clear and Custom becomes active
storefront
Customer filter Select one or more partners; chips below the bar show what is applied
info The Inventory section follows the same range as the orders section — change the range once and both update together.

grid_view KPI Tiles and Partner Cards

shopping_cart
Total Orders Every order in the range. Click to open the full list.
warning_amber
Status tiles One tile per status — New, Synced, Shipped, Error and so on. Click any tile to see just those orders.
store
Partner cards Order count per trading partner. Expand a card to see that partner's status breakdown.
inventory_2
Inventory section Feed batches in the same range — how many are processing, completed or errored.
refresh The page refreshes itself every 15 minutes. Use the refresh button in the header when you need the numbers right now.

open_in_new The Drill-Down Window

Clicking a tile, a partner card or a status inside a card opens the matching orders. What you see there:

confirmation_number
Customer PO The purchase order number the marketplace sent
receipt_long
ERP SO No Sales Order created in the ERP — shown once the order has reached it
schedule
ERP Sync Date When the ERP created that Sales Order
local_shipping
ERP Shipped Date Latest shipment date returned by the ERP. Shown for Shipped, Partially Shipped and Cancelled only.
visibility These ERP columns appear for orders that already exist in the ERP — Total Orders, Synced, Shipped, Cancelled, Partially Shipped, Partially Cancelled. New and error views keep the shorter layout.

touch_app Actions Inside the Drill-Down

The Actions column sits first so it is always reachable, even on wide tables:

visibility
View Order

Opens the full order — shipping address, line items, quantities and line statuses.

folder_open
Show Files

Opens the Order Logs window — every exchange between eSyncMate, the ERP and the marketplace, with download and preview for each file.

refresh
Re-Process

Shown only for errored orders. Retries sending the order to the ERP.

error_outline An ⓘ beside a status means the ERP returned a reason. Hover the status to read the error type, when it happened and each item-level message.
